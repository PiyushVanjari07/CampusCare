College Helpdesk Bot (Student Support Chatbot - Flask + TF-IDF)

1. Install Python 3 and open this folder in VS Code / terminal.
2. pip install -r requirements.txt
3. py test_bot.py        (optional: check matching and scores)
4. py app.py
5. Open http://127.0.0.1:5000 in the browser.

Edit faq.json to add your own college questions and answers.
Conversations are saved in chat_log.csv.
